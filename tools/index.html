Hollowmark tools

Preview and check pages for the P0 offline client.

  • kit.htmlEvery kit prop kind and variant on a turntable, with labels and triangle counts.
  • rig.htmlOne of each rig kind cycling through every animation, plus each class palette.
  • zone.html2D map of a generated layout for a seed: cells, paths, props, packs, exits, spawn, reachability.
  • golden.htmlRecomputes the pinned hashes in this browser and prints PASS/FAIL per key with the user agent.
  • ../index.htmlThe game itself: the offline client at the repo root.

These pages use ES module imports, so they need a web server rather than a file:// URL. From the repo root run node tools/serve.js and open http://localhost:8642/tools/.
